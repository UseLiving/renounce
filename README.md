# RENOUNCE ($RNCD)

A memecoin launchpad where every coin is renounced. No dev wallet, no owner. Buybacks and burns run on their own.

**Live site:** https://useliving.github.io/renounce/  
**X:** https://x.com/UseRenounce

## What's on the site
- A retro desktop over a pixel-art office at 3am: live clock, spinning empty chair, sleeping cat, amber CRT
- Draggable windows, taskbar and Start menu
- Coins by Trending, Starting, New and Graduated, with countdowns and launch baskets
- launch.exe wizard to start your own (simulated) coin
- burns.log terminal you can type into (try `help`)
- Burn alerts for coins you watch, fee split, $RNCD burn stats, readme and how it works
- Screensaver after a minute idle

Single self-contained `index.html`.

> Pre-launch: coins, burns, stats and receipts on the site are samples or simulations. Memecoins are extremely risky. Not financial advice.
